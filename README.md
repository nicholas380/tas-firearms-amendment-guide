# Tas Firearms Amendment Guide

A separate, mobile-first public information website explaining the 21 proposed amendments in the Tasmania Firearms Amendment (Miscellaneous) Bill 2026.

## Publish with GitHub Pages

1. Upload all files in this folder to the root of your `tas-firearms-amendment-guide` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.

Expected address:

`https://nicholas380.github.io/tas-firearms-amendment-guide/`

## Files

- `index.html` — page structure
- `styles.css` — responsive styling
- `data.js` — amendment content
- `app.js` — search, filtering and detailed guide panels

## Important

This is an independent explanatory guide, not legal advice. Important details should be checked against the consultation Bill and the current Firearms Act 1996.
