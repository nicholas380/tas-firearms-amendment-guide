# Tas Firearms Submission Builder

A mobile-first independent consultation tool for Tasmania's Firearms Amendment (Miscellaneous) Bill 2026.

## Features

- All 21 proposed amendments
- Neutral plain-English summaries
- Current-versus-proposed comparison
- Support, oppose, unsure and no-comment choices
- Optional suggested reasons and free-text comments
- Automatic browser saving
- Completion validation
- Generated submission, clipboard copy, addressed email and print/PDF

## Privacy

This is a static website. Responses are stored only in the user's browser using `localStorage`. The site has no server, database, analytics or submission collection.

## Publish with GitHub Pages

Upload all four files to the repository root:

- `index.html`
- `styles.css`
- `data.js`
- `app.js`

Then open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and save.
